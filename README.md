## 零门槛体验（推荐）

工程根目录提供了**两个双击启动脚本**（服务端会自动拉起，无需手动敲命令）：

| 脚本 | 双击后 |
|---|---|
| **`启动-网页检测端.bat`** | 自动启动 MySQL检查 → 视觉服务(9000) → Web后端(8080)，然后**自动打开浏览器**到 `http://localhost:8080/track.html`（把视频**拖进网页 / Ctrl+V 粘贴**即可检测） |
| **`启动-管理端.bat`** | 同上自动启动服务，然后自动打开 `http://localhost:8080/admin.html`（admin / 123456） |

说明：
- 服务已运行时脚本会**自动跳过启动**，只打开浏览器（可反复双击）；
- 脚本启动的服务窗口为最小化，日志保留在任务栏；关闭脚本窗口**不影响**服务运行；
- 若 MySQL 未运行，脚本会尝试自动启动，失败时会给出提示（需要以管理员身份手动启动 MySQL 服务）。

## 手动启动方式（等价于双击脚本）

### 环境要求
| 组件 | 版本 |
|---|---|
| JDK | 17 |
| MySQL | 8.0（默认 root / 123456，可在 application.yml 修改） |
| Python | 3.10+，依赖 `opencv-python fastapi uvicorn python-multipart imageio-ffmpeg`（imageio-ffmpeg 用于把结果视频转码为 H.264，供浏览器直接播放） |
| 微信开发者工具 | 仅运行小程序端需要 |

### 第 1 步：初始化数据库
```bash
mysql -uroot -p123456 < 01-代码/server/sql/init.sql
```

### 第 2 步：启动视觉服务（端口 9000）
```bash
cd 01-代码/vision
pip install opencv-python fastapi uvicorn python-multipart imageio-ffmpeg   # 首次
python api_service.py --host 127.0.0.1 --port 9000
# 浏览器打开 http://127.0.0.1:9000/ 查看服务状态页
```

### 第 3 步：启动 Web 后端（端口 8080）
```bash
cd 01-代码/server
java -jar target/track-server-1.0.0.jar
# 或源码方式: mvn spring-boot:run
```
启动后自动创建管理员 **admin / 123456**。

### 第 4 步：打开页面
| 页面 | 地址 | 说明 |
|---|---|---|
| 系统首页 | `http://localhost:8080/` | 两个入口导航 |
| **网页检测端** | `http://localhost:8080/track.html` | **拖拽/粘贴视频 → 框选/自动目标 → 检测 → 结果回看**（自动登录体验账号 webdemo） |
| Web 管理端 | `http://localhost:8080/admin.html` | admin / 123456 |
| 视觉状态页 | `http://127.0.0.1:9000/` | 含接口文档 /docs |
| 小程序端 | 微信开发者工具导入 `01-代码/miniprogram` | 勾选“不校验合法域名”，真机预览需把 app.js 的 baseUrl 改为局域网 IP |

### 网页检测端操作说明
1. 把 mp4/avi/mov/mkv 视频**拖进虚线框**，或点击选择文件，或在页面内按 **Ctrl+V** 粘贴；
2. （可选）点“提取首帧·画框选目标”，在画布上拖拽框住要跟踪的目标；
3. 点“开始检测”，页面自动轮询，完成后播放结果视频并显示 帧数/FPS/丢失/找回 统计；
4. 下方“我的检测记录”可随时回看历史结果。

## 常见问题

- **上传后任务 FAILED**：确认视觉服务已启动；管理端/网页检测端会显示错误原因；检查
  `server/src/main/resources/application.yml` 中 `app.vision-url`。
- **网页里点"提取首帧"没反应 / 结果视频黑屏**：多为视频编码问题。浏览器只支持 H.264 等格式，
  OpenCV 的 mp4v(MPEG-4) 编码无法在浏览器解码。本项目已自动把**结果视频转码为 H.264**；
  若你的**源视频**无法在浏览器预览取帧，请改用 mp4(H.264) 源文件（手机拍摄的一般都可以），
  或直接跳过取帧使用"自动目标"检测。校验依赖 `pip install imageio-ffmpeg`。
- **点击选择文件弹窗定位到别的文件夹（如桌面 byyl）**：文件选择框的默认目录由操作系统
  "上次打开的文件夹"决定，网页无法指定。**推荐直接把视频文件从文件夹拖进网页虚线框**即可。
- **页面打不开 / 出现"崩溃页、连接失败、Whitelabel"**：几乎都是**后端服务停止了**（如电脑重启、
  关闭了服务窗口、或之前由调试会话启动的服务被清理）。解决办法：双击项目根目录的
  `启动-网页检测端.bat` 或 `启动-管理端.bat` —— 脚本会检测端口，服务没在跑就自动拉起，
  然后打开浏览器。正常使用请**优先用这两个脚本启动**，服务会以独立窗口常驻后台。
- **双击脚本没有反应**：确认在工程根目录双击；首次运行 Windows 若提示“安全警告”点“仍要运行”；
  若 MySQL 未启动且自动启动失败，请以管理员身份手动启动 MySQL 服务后重试。
- **网页检测端无法粘贴视频**：需在页面处于激活状态时按 Ctrl+V；部分浏览器需先点击页面。
- **真机小程序上传失败**：app.js 的 baseUrl 改为电脑局域网 IP，开发者工具勾选“不校验合法域名”。
- **中文乱码**：代码均为 UTF-8；Windows 控制台乱码不影响功能与文件本身。
