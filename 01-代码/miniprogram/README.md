# 小程序端 —— 怎么运行（重要）

## ⚠️ 不要双击 `app.js` 之类的文件

Windows 上 `.js` 默认由 **Windows Script Host** 打开，双击等于"执行脚本"，
会弹出这样的错误：

```
脚本: ...\miniprogram\app.js
行: 14   错误: 缺少 ...   代码: 800A03EB
```

**这不是代码有问题**，而是用错了运行环境：WSH 内置的 JScript 是很老的引擎，
不支持小程序使用的 ES6 语法（`onLaunch() {}` 简写方法、`const`、箭头函数等），
所以一到 `app.js` 第 15 行就报语法错误。

## ✅ 正确运行方式

1. 下载安装 **微信开发者工具**：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
   （选「稳定版 Stable Build」→ Windows 64 位）
2. 打开后选 **导入项目**：
   - **目录**：选中本文件夹（`01-代码/miniprogram`），注意是这一层，不是仓库根目录
   - **AppID**：点「测试号」即可（工程里已填 `touristappid`，无需注册）
3. 点「确定」后模拟器就会加载出小程序（底部三个 tab：上传跟踪 / 我的记录 / 我的）

## 前置条件：后端必须在运行

小程序要调用 `http://127.0.0.1:8080`，所以请先在仓库根目录双击
`启动-网页检测端.bat`（或 `tools\start_all.ps1`）把后端跑起来。

- **模拟器调试**：用 `127.0.0.1` 即可（`project.config.json` 里已设 `urlCheck: false`，
  允许 http 明文请求，无需配置域名白名单）。
- **真机预览**：手机上的 `127.0.0.1` 指向手机自己，必须改成电脑的局域网 IP，
  例如 `app.js` 里改为 `baseUrl: 'http://192.168.1.5:8080'`（用 `ipconfig` 查），
  并保证手机与电脑同一 Wi-Fi。

## 账号

小程序端需要自己注册：登录页 → 注册 → 填用户名/密码/昵称。
（管理端 `admin/123456` 是 ADMIN 角色，不要用于小程序登录测试。）

# 在手机上打开（真机预览）

小程序**不能像网页那样直接打开**，它只能运行在微信里。要在手机上跑，必须用开发者工具的
**「预览」** 生成二维码，再用微信扫码打开。完整步骤如下。

## 第 0 步：确认工程里的 AppID 是「测试号」，不是 `touristappid`

`project.config.json` 里若仍是 `"appid": "touristappid"`，那是**游客模式**——只能在模拟器里跑，
**不支持预览/上传到真机**。

解决办法（免费，一分钟）：

1. 打开 https://mp.weixin.qq.com/wxamp/sandbox?doc=1 ，用微信扫码，即得到一个**小程序测试号**
   （会分配一个真实的 AppID）
2. 回到开发者工具：**详情 → 基本信息 → AppID**，把 `touristappid` 换成测试号的 AppID
   （或直接改 `project.config.json` 的 `appid` 字段）

## 第 1 步：电脑上把后端跑起来

双击仓库根目录的 `启动-网页检测端.bat`（或 `tools\start_all.ps1`），确认 8080 在监听。

## 第 2 步：手机与电脑连同一个 Wi-Fi

`app.js` 里的 `baseUrl` 已设为电脑的局域网 IP（如 `http://10.100.0.36:8080`）。
**电脑换网络后 IP 会变**，用 `ipconfig` 查到新的 IPv4 地址后同步修改 `app.js`。

> 手机和电脑不在同一网段（例如电脑插网线、手机连 4G）时，手机连不上后端，
> 预览里会一直转圈或提示网络错误。

## 第 3 步：先自测一下网络通不通（强烈建议）

**用手机浏览器**打开 `http://<电脑IP>:8080/`：

- 能打开页面 → 网络没问题，继续下一步
- 打不开 → 先排查：是否同一 Wi-Fi、Windows 防火墙是否放行 8080
  （本机已加过入站规则 `Single Object Tracking 8080`）

## 第 4 步：预览

1. 开发者工具工具栏点 **预览** → 生成二维码
2. 用**手机微信**扫码 → 小程序就在微信里打开了（这是「开发版」）
3. 首次打开后，点右上角 **「…」→ 打开调试**，否则真机会拦截 http 明文请求
   （模拟器不受影响，因为 `urlCheck: false` 只对模拟器生效）

## 关于电脑端的服务

真机预览时后端必须一直开着，因为视觉处理全部在电脑上跑，手机只是界面。
手机上传的视频会传到电脑，处理完的结果视频再由手机从电脑拉回来播放。
